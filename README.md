# That’s So Chic TO — Event Decor Website

A responsive website project for an event styling and rentals
business serving the Greater Toronto Area and beyond.

## Features

- Navigation links to each page section
- Hero section with a contact link
- About and services sections
- Responsive image gallery
- Instagram inquiry link
- Smooth scrolling that respects reduced-motion preferences

## Built With

- HTML
- CSS

## Run Locally

Download or clone the project, then open index.html in a browser.
No installation or build step is required.

## Project Status

The first version of the page is complete. The gallery currently
uses temporary sample images. These do not represent the
business’s completed work and will be replaced with approved
business photos before deployment.

## What I Practiced

- Structuring a page with semantic HTML
- Creating responsive layouts with Flexbox and CSS Grid
- Linking to sections using IDs
- Adding descriptive image alternative text
- Reusing CSS classes
- Respecting reduced-motion preferences
